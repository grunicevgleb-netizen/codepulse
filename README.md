## Описание

CodePulse — расширение для Visual Studio Code, которое отслеживает время работы с файлами и проектами.

Расширение позволяет посмотреть, сколько времени было потрачено на каждый файл, и сравнить активность в разных проектах.

## Возможности

- Автоматический подсчёт времени работы.
- Статистика по отдельным файлам и проектам.
- Поддержка обычных текстовых файлов.
- Визуализация статистики с помощью диаграмм.
- Просмотр активности за сегодня, последние 7 дней и всё время.
- Сохранение статистики между запусками VS Code.
- Автоматическое обновление Dashboard.
- Приостановка подсчёта при бездействии более 60 секунд.

## Запуск

Для запуска нужно установить Node.js и открыть проект в VS Code.

В терминале выполнить:

```bash
npm install
npm run compile
```

После этого нажать `F5`.

Чтобы открыть статистику, нужно вызвать палитру команд `Ctrl + Shift + P` и выбрать `CodePulse: Open Dashboard`.
